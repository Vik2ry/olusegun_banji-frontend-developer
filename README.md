## Product questions

### Who uses it?
Space enthusiasts exploring SpaceX's rockets. It was built as a front-end developer challenge, so the realistic "user" is a reviewer judging the code and the UI.

### What problem does it solve?
It turns SpaceX's public rocket API into a browsable page: a searchable, paginated list of rockets with a detail modal for each, plus loading states.

### Why would someone pay for it?
They wouldn't. It is a challenge submission that demonstrates working with a public API, search, pagination and responsive UI, not a commercial product.
